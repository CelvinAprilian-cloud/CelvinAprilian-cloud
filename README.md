## ✨ Fitur Utama

1. **Modern Glassmorphism Aesthetic:** Menggunakan efek transparansi latar belakang halus, `backdrop-filter: blur()`, dan batas semi-transparan yang memberikan kesan kedalaman (*depth*).
2. **Sistem Desain Variabel CSS (CSS Variables):** Mengatur palet warna terpusat (`--background`, `--surface`, `--text`, `--accent`) yang memudahkan penyesuaian tema secara dinamis.
3. **Dual-Theme Experience (Light & Dark Mode):** Desain mode gelap terintegrasi yang kontras dan nyaman di mata untuk penggunaan malam hari.
4. **Fluid & Mobile-Friendly Layout:** Pemanfaatan fungsi CSS `clamp()` dan media queries agar komponen kartu tetap proporsional dari layar smartphone hingga monitor desktop lebar.
